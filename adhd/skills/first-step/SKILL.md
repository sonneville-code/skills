# First step

Starting is the hardest step for an ADHD reader. This skill turns one stuck task into a physical first action that takes under two minutes.

## Steps

1. **Pick one task.** Overwhelm with many items: choose the one with the nearest hard deadline, or a skipped meal, sleep or chore first when basic needs were skipped today. Say the pick in one line with its reason. The user can swap it with one word.
2. **Check the body first.** Meal, water, sleep, time of day. If one is off, the first step is its countermeasure: "Water and a 5-minute walk, then open the report." Inside the user's quiet hours, the first step is going to bed, and the task goes first in tomorrow's focus block.
3. **Break it down to the right size.** Ask nothing. Pick the size from how stuck the user sounds:
   - mild: 3 to 5 steps.
   - stuck: 5 to 8 steps, each one physical and under 10 minutes.
   - frozen: only the first step, written as a body movement: "Open `report.docx` and read the last paragraph you wrote."
   Each step gets a time estimate in minutes.
4. **Remove the friction** you can remove yourself: open or create the file, fetch the assignment text, draft the first sentence, find the form. Say what is ready in one line.
5. **Give one next action**, under two minutes, and stop. No plan for the rest of the day.

Done when the user has one action that needs no further decision.

## Tone

State facts without blame. "The report carried forward 3 days" is a fact. Name no cause and add no pep talk. Progress replies are short: "Paragraph 1 done. Next: the data table, 10 minutes."
