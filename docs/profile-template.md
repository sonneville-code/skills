# Profile template

`val-mode`, `scope-guard`, `first-step` and `diverge` read a profile when one exists. Copy this file to `~/.config/containment/profile.md`, or point `CONTAINMENT_PROFILE` at it. Keep it out of any public repository: it describes you.

Every key is optional. A missing key means the skill asks once or skips that step.

## Settings

- ledger: path to the file that lists what is due today and your open tasks
- later list: the section of the ledger where parked ideas go
- deadlines: where upcoming deadlines live (a note, a calendar, a course page)
- quiet hours: when to wind down, for example `wind down 21:00, lights-out 22:30, wake 06:00`
- inside quiet hours: what the agent does, for example `finish or checkpoint, start nothing new`
- wording: how you want hard news phrased, for example `facts, never blame; one reminder per topic`
- decisions: how you want choices asked, for example `one batched question, recommendation first`
- agents: how many agents may wait on you at once

## Patterns (optional)

A few lines on what derails you and what helps, written as observations with a date or an example. Agents use them to pick the right size of first step. Two or three honest patterns beat a long list.

## What works (optional)

The replies, formats and tones that help you act. For example: one recommendation instead of a menu, the next physical action first, exact time estimates.
